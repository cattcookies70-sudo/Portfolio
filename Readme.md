## 🌐 Deployment

The portfolio is a static HTML/CSS/JavaScript website and can be deployed using GitHub Pages.

Recommended repository structure:

```text
index.html
style.css
script.js
assets/
```

After pushing the project to GitHub:
1. Go to **Repository** → **Settings** → **Pages**
2. Select **Deploy from branch** → **main** → **`/ (root)`**

The website can then be accessed through the generated GitHub Pages URL.
